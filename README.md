# 蔡政霖 Cheng-Lin Tsai 個人網站

AI Agent、企業應用與人才賦能。白色簡約介面、Google Sans Flex / Noto Sans TC、Flaticon UIcons Regular Rounded 圖示。

網站：https://mela0976.github.io/ai-trainer-profile/

GitHub：https://github.com/mela0976

## 預覽

```sh
python3 -m http.server 4173
```

`index.html` 為內容；`style.css` 為版面；`app.js` 為情境切換、手機導覽與分享互動。GitHub Pages 從 main 根目錄部署。Google Sites 以整頁嵌入此網站，更新GitHub Pages後即可顯示新版。

AI Agent 工作台為流程示意，不呼叫實際模型。教學規模依本人原站累積紀錄，非即時統計。

## 圖示來源

Uicons by [Flaticon](https://www.flaticon.com/uicons)，4.0.0 Regular Rounded。使用17個glyph的本地webfont子集，保留原輪廓；頁尾保留署名。來源與授權入口記錄於 `assets/icons/SOURCE.md`。
